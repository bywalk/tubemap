# 📍 TubeMap Travel - 한국 여행 유튜버 에디션

한국 대표 여행 유튜버(빠니보틀, 곽튜브, 원지의 하루, 채코제, 여행가 제이, 잰잰바리 등)의 실제 여행 영상과 추천 스팟, 꿀팁을 **지도(Map)**와 **데이터 테이블(Table)**로 시각화한 웹 애플리케이션입니다.

---

## 🌟 주요 기능

1. **한국 대표 여행 유튜버 큐레이션 데이터**
   - **빠니보틀**: 이집트 다합(홍해 다이빙), 인도 바라나시(갠지스강/아시 가트), 델리 시장
   - **곽튜브**: 아제르바이잔 바쿠(올드시티/샤슬릭), 우즈베키스탄 사마르칸트(레기스탄 광장/플로프)
   - **원지의 하루**: 몽골 테를지 국립공원(게르 캠프/은하수), 태국 치앙마이(님만해민/원님만)
   - **채코제**: 태국 방콕(카오산로드/쩟페어 랭쌥), 라오스 방비엥(블루라군/버기카)
   - **여행가 제이**: 튀르키예 카파도키아(괴레메 열기구/항아리케밥), 모로코 사하라 사막(메르주가)
   - **잰잰바리**: 우즈베키스탄 타슈켄트(초르수 바자르), 조지아 카즈베기(게르게티 만년설 교회)

2. **유튜버별 / 지역별 탭 필터링**
   - `👤 유튜버별`: 크리에이터 칩을 클릭하면 해당 유튜버의 전 세계 여행 경로만 모아보고 지도가 자동 줌인됩니다.
   - `🌍 국가/지역별`: 동남아, 중앙아시아, 코카서스, 중동/아프리카, 남아시아 등 대륙/지역별 묶어보기 지원.

3. **📊 데이터 테이블 뷰 (Table View)**
   - 헤더의 **'📊 테이블 표 보기'** 버튼을 누르면 전체 여행지 데이터를 엑셀/노션처럼 한눈에 조회.
   - 유튜버, 국가, 스팟명 기준 **실시간 오름차순/내림차순 정렬** 지원.
   - 테이블 내 실시간 키워드 검색.
   - 테이블에서 바로 **'▶ 영상'** 재생 또는 **'📍 지도'** 핀으로 점프 가능.
   - **'📥 CSV 다운로드'**: 엑셀 한글 깨짐 방지(UTF-8 BOM)가 적용된 CSV 파일로 저장.

4. **영상 속 💡 유튜버 꿀팁 & 구글 지도 연동**
   - 마커 팝업 및 재생 모달에서 유튜버의 실제 조언(예: "일출 보트 투어 추천", "볼트 앱 이용", "난로 장작 필수") 노출.
   - 주요 타임스탬프 바로가기 챕터 버튼 지원.
   - '구글 지도에서 보기' 원클릭 연동.

5. **새 여행지 등록 & 지도 좌표 픽커**
   - 유튜브 링크 입력 시 썸네일 자동 추출.
   - 지도 위를 클릭하여 경도/위도를 1초 만에 입력하는 '🎯 지도에서 선택' 모드 지원.
   - 로컬스토리지(`localStorage`) 자동 저장.

## 🤖 신규 영상 자동 수집기 (`collector.py`)

매주 새로 올라오는 여행 영상들을 자동으로 가져와 `js/data.js`에 핀으로 추가하는 파이썬 스크립트입니다.

### 실행 방법
```bash
cd /Users/bongsok/dev/tubemap

# 1. 대화형 실행 (신규 영상 발견 시 추가 여부 물어봄)
python3 collector.py

# 2. 완전 자동 실행 (배치 작업용)
python3 collector.py --auto
```

### 동작 원리
1. **YouTube 공식 RSS 피드 활용**: 봇 차단 및 API 할당량 걱정 없이 채널별 최신 영상을 무료로 0.1초 만에 조회.
2. **중복 필터링**: 이미 `js/data.js`에 있는 영상은 건너뜁니다.
3. **위치 & 꿀팁 분석**: 제목과 설명글에서 여행 국가, 도시, 스팟명을 감지.
4. **OpenStreetMap 지오코딩**: 장소명에 맞는 위도와 경도 좌표를 자동 추출하여 지도 핀을 생성.

### 🌐 GitHub Actions 무인 자동화 연동
`.github/workflows/weekly_crawler.yml` 파일이 포함되어 있어, 이 저장소를 GitHub에 올리면 **매주 월요일 오전 9시(KST)마다 GitHub Actions가 자동으로 `collector.py`를 실행하고 새 영상을 커밋&배포**합니다.
