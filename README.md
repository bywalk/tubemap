# 📍 TubeMap Travel (`tubemap`)

> 한국 대표 여행 유튜버들의 실제 여행 영상과 추천 스팟, 꿀팁을 **지도(Map)**와 **데이터 테이블(Table)**로 시각화한 인터랙티브 웹 애플리케이션입니다.

🌐 **라이브 웹사이트**: [https://bywalk.github.io/tubemap/](https://bywalk.github.io/tubemap/)

---

## 🌟 주요 기능

### 1. 👥 한국 대표 여행 유튜버 (구독자 5만 ~ 100만+) 큐레이션
- **모니터링 대상 크리에이터 (총 13팀)**:
  - **메가급**: 빠니보틀, 곽튜브, 희철리즘
  - **대형**: 노마드션, 원지의 하루, 채코제, 여행가 제이, 잰잰바리, 캡틴따거, 캐럿맨 여행기, 또떠남, 쏘이 The World, 초마드
- **영상 속 💡 유튜버 꿀팁 & 후기**: 현지 교통 팁, 맛집 주문법, 안전 유의사항 등 유튜버의 실전 조언을 마커 팝업 및 상세 모달에서 바로 확인.
- **주요 챕터(타임스탬프) 점프**: 영상 속 특정 명소나 맛집이 나오는 시간대로 원클릭 이동.
- **🗺️ 구글 지도 연동**: 여행 중 길을 바로 찾을 수 있도록 구글 지도 길찾기 링크 제공.

### 2. 📅 여행 정보 최신성 보장 (1년 이내 영상 필터링)
- 여행지의 물가, 폐업 여부, 비자 규정 등의 변동성을 감안하여 **최근 1년(365일) 이내에 업로드된 검증된 최신 영상만 수집 및 표시**합니다.
- 각 카드 및 테이블에 `📅 업로드 날짜`가 명시됩니다.

### 3. 📊 인터랙티브 데이터 테이블 뷰 (Table View)
- 상단 **'📊 테이블 표 보기'** 버튼으로 노션/엑셀 스타일의 데이터 테이블 조회.
- **다양한 정렬 지원**: 유튜버, 국가/도시, 스팟명, **업로드일(최신순)** 기준 오름차순/내림차순 정렬.
- **테이블 내 실시간 검색**: 키워드 입력 즉시 필터링.
- **원클릭 연동**: 표에서 **[▶ 영상]** 즉시 재생 및 **[📍 지도]** 핀 이동 지원.
- **📥 CSV 다운로드**: 엑셀 한글 깨짐 방지(UTF-8 BOM)가 적용된 CSV 파일 내보내기 지원.

### 4. 🧭 동적 유튜버별 & 지역별 필터링
- `👤 유튜버별`: 크리에이터 칩을 누르면 해당 유튜버의 전 세계 여행 동선만 모아보고 지도가 자동 포커스됩니다. (새 유튜버가 추가되면 칩도 자동 생성)
- `🌍 국가/지역별`: 동남아, 중앙아시아, 코카서스, 중동/아프리카, 남아시아 등 대륙별 모아보기.

### 5. 🎯 새 여행지 등록 & 지도 좌표 픽커
- 유튜브 링크 입력 시 썸네일 자동 추출.
- **'🎯 지도에서 선택'** 모드로 지도의 원하는 장소를 클릭하면 위도/경도가 1초 만에 자동 입력.
- 브라우저 로컬 스토리지(`localStorage`)에 영구 저장.

## 🤖 신규 영상 자동 수집기 (`collector.py`)

매주 새로 올라오는 여행 영상들을 자동으로 가져와 `js/data.js`에 핀으로 추가하는 파이썬 스크립트입니다.

### 동작 원리 & 정책
1. **YouTube 공식 RSS 피드 활용**: 봇 차단 및 API 할당량 걱정 없이 채널별 최신 영상을 무료로 수집.
2. **1년 이내 최신성 검사 (`MAX_VIDEO_AGE_DAYS = 365`)**: 1년 이상 경과된 과거 영상은 자동으로 제외하여 신선한 여행 정보만 유지.
3. **중복 필터링**: 이미 등록된 영상 ID는 자동으로 건너뜁니다.
4. **여행 장소 & 꿀팁 분석**: 제목과 설명글에서 국가, 도시, 스팟명을 감지.
5. **OpenStreetMap 지오코딩**: 장소명에 맞는 위도와 경도 좌표를 자동 추출하여 지도 핀을 생성.

### 실행 방법 (로컬)
```bash
cd /Users/bongsok/dev/tubemap

# 1. 대화형 실행 (신규 영상 발견 시 추가 여부 확인)
python3 collector.py

# 2. 완전 자동 실행 (배치 작업용)
python3 collector.py --auto
```

## 🌐 GitHub Actions 주간 무인 자동화

`.github/workflows/weekly_crawler.yml` 워크플로우가 등록되어 있어:
- **매주 월요일 오전 9시 (KST)**에 GitHub Actions가 자동으로 `collector.py --auto`를 실행합니다.
- 새로운 여행 영상이 발견되면 `js/data.js`를 갱신하고 자동 커밋 & 푸시합니다.
- 변경 사항이 푸시되면 GitHub Pages가 10초 만에 웹사이트를 자동 갱신합니다. (서버 비용 $0원)

## 🚀 로컬 실행 방법

[index.html](file:///Users/bongsok/dev/tubemap/index.html)을 더블 클릭하여 크롬이나 사파리로 엽니다.

터미널에서 아래 명령어를 실행 후 브라우저에서 `http://localhost:8000`에 접속합니다:

python3 -m http.server 8000
